## 📥 Cómo Exportar para Presentación

### Diagramas Mermaid a PNG
1. Abrir archivo .md en VS Code
2. Instalar extensión "Markdown Preview Mermaid Support"
3. Preview del markdown (Ctrl+Shift+V)
4. Click derecho en diagrama → "Copy as Image"
5. Pegar en PowerPoint/Google Slides

### Alternativa - Mermaid Live Editor
1. Copiar código Mermaid
2. Ir a https://mermaid.live
3. Pegar código
4. Descargar como PNG/SVG

### Tablas a Excel
1. Copiar tabla de markdown
2. Pegar en Excel (mantiene formato)
3. Aplicar estilos según necesidad
